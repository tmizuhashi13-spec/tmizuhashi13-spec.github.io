US Stock Live Month-End

US Stock Live Month-End is a personal-use automation application used by its owner to run a private U.S. stock analysis workflow.

The application connects to the owner's Google Drive so that an automated GitHub Actions workflow can access the owner's analysis files required for the scheduled month-end process.

The application is not offered as a public investment service, does not accept public user registrations, and is intended solely for personal use by the application owner.

Google Drive use

Google Drive access is used only for the owner's own files needed by the automated analysis workflow. The application does not sell Google user data.
