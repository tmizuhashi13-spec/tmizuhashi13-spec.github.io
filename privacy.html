Privacy Policy

US Stock Live Month-End is a personal-use application operated solely for the application owner's own automated U.S. stock analysis workflow.

Google user data accessed

The application may access files and folders in the application owner's Google Drive as authorized by the owner through Google OAuth.

How the data is used

Google Drive data is used only to read and write files required by the owner's scheduled analysis and automation workflow.

Storage and processing

OAuth authorization information required for automated operation may be stored as an encrypted repository secret in GitHub Actions. Analysis data may be processed temporarily by GitHub-hosted Actions runners in order to execute the owner's workflow.

Sharing

The application does not sell Google user data. Data is not intentionally shared with third parties except for service providers required to operate the workflow, including Google Drive and GitHub Actions.

Retention

Files remain under the owner's control in Google Drive. Temporary workflow environments may be destroyed after an automation run completes. Authorization can be revoked by the owner through the Google Account security settings.

Personal-use limitation

This application is not offered to the general public and does not support public account registration.
